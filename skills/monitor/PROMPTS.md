## 高级用法示例

### 场景1：排查特定IP的网络问题
```
帮我查看192.168.1.100的网络活动：
1. 先看最近的20个数据包
2. 再查相关的功能调用
3. 最后查看它的套接字状态
```

### 场景2：分析HTTPS流量
```
分析443端口的HTTPS流量：
1. 获取目标端口443的数据包
2. 查看相关的发送/接收功能调用
3. 显示对应的套接字
```

### 场景3：系统网络状态检查
```
做一个完整的网络状态检查：
1. 健康检查
2. 查看所有套接字
3. 获取最近数据包
4. 显示功能ID映射表
```

### 场景4：特定连接追踪
```
追踪192.168.1.50到8.8.8.8的连接：
1. 查询这两个IP之间的数据包
2. 查看相关的功能调用
3. 检查套接字状态
```

## 工具映射表

| 用户意图 | 推荐工具 |
|---------|---------|
| 获取最近数据包 | `get_recent_packets` |
| 搜索特定数据包 | `query_packets` |
| 查看功能调用 | `get_recent_map` |
| 查函数名称 | `get_function_name` |
| 看发送函数 | `query_func_send` |
| 看接收函数 | `query_func_recv` |
| 列所有套接字 | `get_socket_list` |
| 看已建立连接 | `get_established_tcp_sockets` |
| 查探针状态 | `is_attach_finished` |
| 健康检查 | `health_check` |
| 看可用工具 | `server_capabilities` |
