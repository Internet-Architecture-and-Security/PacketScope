## 工具映射表

| 用户意图 | API 端点 |
|---------|---------|
| 查看连接 | `GET /api/connections` |
| 查看ICMP | `GET /api/icmp` |
| 查看统计 | `GET /api/stats` |
| 列出过滤器 | `GET /api/filters` |
| 创建过滤器 | `POST /api/filters` |
| 更新过滤器 | `PUT /api/filters/{id}` |
| 删除过滤器 | `DELETE /api/filters/{id}` |
| 启用过滤器 | `POST /api/filters/{id}/enable` |
| 禁用过滤器 | `POST /api/filters/{id}/disable` |
| AI状态 | `GET /api/ai/status` |
| AI配置 | `GET /api/ai/config` / `POST /api/ai/config` |
| AI分析 | `POST /api/ai/analyze` |
| AI生成规则 | `POST /api/ai/generate` |
| PCAP分析 | `POST /api/pcap/analyze` |
