## 综合场景

### 场景1：安全评估
```
帮我评估到 8.8.8.8 的网络安全状况：
1. 先追踪路由
2. 分析风险和异常
3. 对比历史路径
```

### 场景2：故障排查
```
排查到 www.google.com 的网络延迟问题：
1. 追踪路由路径
2. 检查哪些跳点延迟过高
3. 分析路径异常
```

### 场景3：路径监控
```
监控到 1.1.1.1 的路径变化：
1. 追踪当前路径
2. 对比历史路径
3. 查看是否有新增的异常IP
```

### 场景4：多协议检测
```
用 ICMP 和 TCP 分别追踪到 8.8.8.8 的路径，对比结果
```
